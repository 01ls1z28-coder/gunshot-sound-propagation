    Builds a noise map from starting SPL, environment (temperature, humidity, terrain), and wind — showing how gunshot sound levels fall off with distance across the field. Propagation includes spherical spreading, terrain loss, ground reflection, and a three-band (low/mid/high) weighted sum, plus an optional supersonic shockwave path. Map SPL is an engineering broadband estimate, not certified Lpeak or LAeq.

    How it works (Phase 1): Wind uses a directional refraction-style factor factor = 1 + 0.03·v·cos(θ) clamped to [0.7, 1.3], applied as ΔL = 20·log₁₀(factor) — downwind (cos>0) boosts, upwind (cos<0) attenuates. Atmospheric absorption follows ISO 9613-1:1993 pure-tone attenuation coefficient α (dB/m), Eq. (5), with oxygen/nitrogen relaxation frequencies frO / frN and Annex B humidity (psat/pr); loss is Aatm = α·d at each band center frequency (Hz). Default air pressure is 1 atm (101.325 kPa).

    Phase 2 — peak-style & distance search: Continuous / field SPL is the existing 3-band weighted pipeline (0.45·L125 + 0.35·L1k + 0.20·L4k), with optional shockwave merge via pressure sum. Peak-style ≈ extends that pressure-domain path: pi = 10Li/20 for each band; Lpeak≈ = 20·log₁₀(Σ pi) (+ shock pressure if isSupersonic). This is an engineering upper-bound-style estimate from the same band field — not a measured impulse Lpeak. Distance-to-OSHA rows (85 action, 90/8 h, 95/4 h, 100/2 h, 105/1 h, 115/≤¼ h) binary-search radial distance along downwind (ray = wind dir), upwind (ray = wind + π), and crosswind (ray = wind + π/2) where continuous Propagate equals that dB; off-map → “beyond max distance.” The 140 dB peak row searches the same rays on the peak-style estimate against the OSHA 1910.95 impulsive/impact footnote (≤140 dB peak SPL).

    OSHA reference (29 CFR 1910.95): Map contours show the 85 dBA action level (1910.95(c)(1)–(c)(2)) and selected Table G-16 permissible noise exposures (dBA, slow response): 90 (8 h), 95 (4 h), 100 (2 h), 105 (1 h), and 115 (¼ h or less). Table G-16 / related guidance also states exposure to impulsive or impact noise should not exceed 140 dB peak sound pressure level. G-16 levels are workplace time-weighted / continuous exposure criteria for comparison against the map’s modeled continuous field SPL — not a hearing-safety certification. Gunshots are impulse events; continuous / TWA limits are shown for reference only. Peak-style readout and the 140 dB row are engineering estimates, not certified Lpeak.

    Phase 3 — gun / suppressor profiles & bare vs suppressed: Baked js/profiles-data.js reuses Sound Distance Calculator suppressors-data.js (Thunder Beast Arms Silencer Summit ML dBA @ ~1 m; also SDC credits for public advertised specs and Mrgunandgear measurements). Suppressed source level is the selected row’s measured ml_dba via Propagate(ml_dba, …) — not an invented reduction. Bare uses Custom / manual Starting SPL or a cited Bare Muzzle host row from the same bake. When both are set, Δ = bare − ml_dba is shown for comparison; ApplySuppressor(bare, reduction) runs only when the selected bare host matches the suppressor’s measurement host (bare_ref_id / host_key); otherwise suppressed uses measured ml_dba (host mismatch — no transplanted reduction). Estimates labeled; not lab-certified hearing-safety ratings.

    Disclaimer: values are compiled engineering estimates for visualization and education — not laboratory-certified hearing-protection or regulatory measurements. Measurement setups, hosts, ammo, and conditions differ; do not treat displayed SPL as a guarantee of hearing protection.
